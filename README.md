## ✨ Key Features & Capabilities

- **Interactive 3D Universe Hero**: Cursor-tracking 3D visual, dynamic badge typography, and animated CTA.
- **Cinematic Video Showreel**: High-definition modal player with custom controls and fluid entrance animations.
- **Interactive Story & Heritage**: Dynamic visual timeline covering company milestones with curated imagery.
- **Comprehensive Services Suite**: 6-pillar service architecture with uniform bento cards and deep links.
- **Curated Multi-Category Portfolio**: High-resolution gallery with smart categorized filters (Videography, Photography, Digital).
- **Responsive Navigation & Quick Contact**: Glassmorphic edge-to-edge navbar with right-side drawer and instant contact modal.
- **Performance Optimized**: 60fps animations, manual chunk code-splitting, and optimized asset delivery.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 6 (with manual chunk splitting & optimization)
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism Utilities
- **Motion & Interactions**: Framer Motion 12, GSAP 3.12, Lenis Smooth Scroll
- **Icons**: Lucide React

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
